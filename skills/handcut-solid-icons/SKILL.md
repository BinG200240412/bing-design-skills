# 灰色手绘面型图标

把用户指定的事物或概念做成清楚、克制、有一点手作感的实心标识。古埃及、出行、太阳舟都是案例，不是默认主题。

## 已确认的规范

- **颜色**：默认填充 `#41403D`（sRGB 65, 64, 61），单一纯色。用户明确另定颜色时再改；不用纯黑，也不从生图里吸取近似灰色。
- **面型**：以厚实色块和必要留白构形，内部孔洞用负形。主体不靠细线描边。
- **边缘**：轮廓清晰、曲线顺畅，缩小后仍可辨。模糊、锯齿、光晕、散点不属于手绘感。
- **手作感**：轻微弯曲、倾斜、不对称和比例参差；不规则发生在整体形状上，不用粗糙纹理伪造。
- **扁平**：无渐变、光照、立体、阴影、噪点、排线、缺墨或印刷肌理。不套用 `sudoku-image-style` 的铜版画、黑白占比或粗糙报纸规则。
- **克制**：少量块面表达核心含义；不自动添加文字、徽章外框、神秘学纹饰或背景卡片。

已确认的风格参考：[PNG](assets/solar-barque-reference.png) 与 [可编辑 SVG](assets/solar-barque-reference.svg)。需要对齐时先查看 PNG；参考色块、边缘和不规则程度，不把船和太阳移植进其他主题。圆日太阳舟是此案例的最终选择，带尾迹变体没有被选中。

## 选择工作方式

- **恢复已选版本、改色或导出已有 SVG**：直接复制或编辑矢量，另存新版本，不重新生图。保留已认可的路径。
- **生成新主体或修改形态**：优先用当前环境的内置图像生成工具。编辑本地参考前先查看，区分风格参考与编辑目标。不另起 Codex/Claude 会话绕行生图，也不把 API key 当作内置工具的前置条件。
- **多种方案**：每个主体分别生成，统一色号与视觉分量；不擅自增加方案数量。
- **历史符号选题**：用户要历史含义时，再查博物馆、大学或学术字形资料。区分原本含义与现代设计转译，不把神祇或来世旅程称为古代通用“出行 logo”。

生成／局部修改时按需读取 [提示词模板](references/prompt-templates.md)。已有明确要求就直接做，不重复要求确认；用户选定后再把主观效果记录为已确认。

## 精确填色与矢量交付

提示词不能保证精确 RGB。最终色号在 SVG 填充值中设定并校验，不能把近似灰色生图标成已准确统一。

浅色或透明底的实心标识可运行本技能脚本，路径相对于技能目录：

```bash
python3 scripts/vectorize_icon.py INPUT.png OUTPUT.svg --preview
```

默认色号是 `#41403D`；保留原画布，输出真实路径与透明背景 SVG。`--preview` 在 macOS 用 Quick Look 渲染白底 PNG。缺少依赖时使用：

```bash
uv run --with pillow --with vtracer python scripts/vectorize_icon.py INPUT.png OUTPUT.svg --preview
```

脚本只负责矢量转换、透明底技术归一化和准确填色，不重新设计轮廓。透明输入先在临时白底合成，避免透明区域被误当黑块；不改原始生图。不要用描摹掩盖错误造型或模糊素材。默认拒绝覆盖，迭代时用新文件名。

已有合格 SVG 无需再转成位图描摹；原样恢复时核对路径或文件摘要一致。

## 验收与交付

1. 查看最终 SVG 回渲：主体、孔洞、微小留白、曲线和边缘正确。用于 UI 时也检查 24–32 px 辨识。
2. 检查 `viewBox`、画布尺寸、准确填充色；不得嵌入位图、意外背景矩形或描边。
3. 局部修改检查已确认区域；用户撤回修改时恢复其明确选择的版本。
4. 交付 SVG 与 PNG 预览，保留实际提示词，说明生图后描摹或直接编辑矢量。不要把改扩展名的 PNG 当 SVG。
5. 简短给出文件链接；写成 skill 时可收录已确认参考，不顺带修改记忆、原项目源码或其他技能。
